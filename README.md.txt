# Week 4 – Personal Finance Tracker

## 📌 Project Overview
This project is part of **Week 4: File Handling & Final Project**.  
The goal of this project is to apply Python file handling, modular programming, and error handling concepts by building a **Personal Finance Tracker**.

---

## 📝 Project Description
The Personal Finance Tracker is a Python-based application that allows users to:
- Add expenses
- Categorize expenses
- Store data permanently using files
- View reports and summaries

This project combines concepts from **Weeks 1–4**, including variables, functions, dictionaries, file handling, and modular code structure.

---

## 🛠️ Features
- Add new expenses with category and description
- View all saved expenses
- Search expenses by category
- Generate monthly expense report
- View category-wise expense breakdown
- Save and load data using JSON files
- Error handling for invalid inputs
- Menu-driven user interface
